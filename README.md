# Christoph Wannemacher — Personal Website

**Personal website of Christoph Wannemacher.**

🌐 **Live:** [christoph-wannemacher.de](https://christoph-wannemacher.de/)

> A personal digital space about people, products, innovation and the stories behind them.

The website is available in **German and English** and uses a grayscale, cubic visual language.

---

## Develop

Install dependencies:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

---

## Tech Stack

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **GitHub Pages**

---

## Deployment

The website is automatically deployed via **GitHub Actions**.

```text
Cursor
  ↓
GitHub
  ↓
GitHub Actions
  ↓
Next.js static export
  ↓
GitHub Pages
  ↓
christoph-wannemacher.de
```

## Privacy

The website is intentionally designed to be privacy-friendly:

- No analytics or tracking
- No marketing tools
- No contact form
- No externally embedded content

See the [Privacy Policy](https://christoph-wannemacher.de/privacy/).
